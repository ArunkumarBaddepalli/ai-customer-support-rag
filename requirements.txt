# Pinned exactly, so two deploys of the same source install the same code.
# With >= ranges a minor release of sentence-transformers or psycopg could
# change behaviour between one deploy and the next with nothing in the diff
# to explain it. The Dockerfile already asserts torch is the +cpu build for
# the same reason.
#
# torch is deliberately absent: the Dockerfile installs the CPU-only wheel
# from PyTorch's own index first, because PyPI's default Linux wheel drags in
# ~2.3 GB of CUDA libraries that cannot execute on a CPU instance.
